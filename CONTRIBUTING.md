# Contributing to FORGEX

Thank you for contributing to FORGEX!

## Getting Started

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/your-feature`
3. Install development dependencies: `pip install -e ".[dev]"`
4. Make your changes
5. Run tests: `pytest tests`
6. Run linting: `ruff check src`
7. Run type checking: `mypy src`
8. Commit and push
9. Open a pull request

## Code Style

- Follow PEP 8
- Use type hints
- Run `ruff format src` before committing
- Run `ruff check src` to verify

## Pull Request Process

1. Ensure all tests pass
2. Update documentation if needed
3. Describe your changes in the PR
4. Request review from maintainers

## Reporting Issues

Use GitHub issues to report bugs or request features.
