# Changelog

### Added
- Autonomous agent workflow (Planner, Coder, Reviewer, Tester)
- LangGraph-based multi-agent orchestration
- Local model providers: Ollama, llama.cpp, Transformers
- Hugging Face Hub model downloads
- Repository context engine with file/symbol retrieval
- Persistent SQLite memory store
- MCP client/server and tool registry
- Builtin skills: coding, debugging, testing, refactoring
- Plugin system with registry and loader
- Code verification, change validation, result verification
- Safe Git integration with rollback
- Security permissions, policies, approvals, sandboxing
- Typer CLI with slash commands
- Windows and Linux installers
- C++20 native acceleration (optional via pybind11)
